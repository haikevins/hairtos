# 03 — HairEvent framework


> **Bố cục chuẩn của nhóm:** Mục tiêu → Thành phần → Mô hình dữ liệu → Luồng thực thi → Bất biến → API/cấu hình → Kiểm thử → Giới hạn.


HairEvent là lớp tùy chọn phía trên hairtos. Nó sử dụng queue, task, software timer và critical-section wrapper của kernel.
